# Unstuck

Hackathon demo: help daily earners **afford discretionary wants** without falling back into the rent / advance cycle.

## Hero
**How can I afford this?** — ranked paths: flex, delay, earn, swap, sink, wait.

## Supporting
- Buffer days gauge
- Next cliff (rent/bills)
- Advance fee warning
- Cycle insight (heavy vs calm weeks)

## Run
```bash
npm install
npm run dev
```

Demo data: `public/data/demo.json` (built from sample CSVs via `scripts/build_demo_data.py`).
